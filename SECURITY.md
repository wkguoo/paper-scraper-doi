# Security Policy

This project may touch institutional cookies, browser login state, downloaded PDFs, and local result folders. Treat all of those as private research or credential-adjacent data.

## Do Not Post Sensitive Data

Do not upload or paste any of the following into GitHub Issues, Pull Requests, Discussions, release comments, or public logs:

- `cookie.json`, `cookies.json`, exported browser cookies, session tokens, or account passwords.
- Downloaded PDFs, supplementary files, result folders, CSV/XLSX reports, or private bibliography exports.
- Screenshots of university, library, publisher, proxy, VPN, CARSI, or other internal institution pages.

## Reporting Security Issues

If you find a security issue, report it privately to the maintainer instead of opening a public Issue. Use a private GitHub message if available, or contact the maintainer through the public profile information for `wkguoo`.

Please include a concise description, affected files or commands, and safe reproduction steps that do not expose credentials, cookies, PDFs, institution screenshots, or private research data.

## Out of Scope

This project does not accept requests to defeat CAPTCHA or human verification. Please do not paste cookies, passwords, PDFs, or institution screenshots into issue reports.
